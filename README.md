# SI-PERMAI
SI-PERMAI adalah aplikasi pelaporan masyarakat berbasis web yang memudahkan warga Kabupaten Tangerang menyampaikan keluhan, aspirasi, dan laporan berbagai permasalahan secara langsung kepada instansi terkait. Aplikasi ini membantu mempercepat komunikasi, penanganan, dan tindak lanjut masalah secara lebih efektif dan transparan.
