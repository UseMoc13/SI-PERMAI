# SI-PERMAI (Sistem Pelaporan Masyarakat Inisiatif)

## Overview

SI-PERMAI is a web-based public reporting platform designed to bridge communication between the government and citizens of Tangerang Regency. The system enables residents to submit complaints, suggestions, and reports regarding various public issues directly to the responsible authorities.

By providing a centralized reporting platform, SI-PERMAI helps improve transparency, accelerate issue resolution, and support more effective public service management.

---

## Project Objectives

* Improving the Efficiency of Complaint Handling
* Increasing Public Participation in the Oversight of Public Services
* Strengthening Local Government Transparency and Accountability
* Providing Easy-to-Use, Integrated Communication Channels
* Reducing the Number of Unresolved Complaints
* Increasing Public Satisfaction with Public Services

---

## Prototype Flow

### 1. Admin Dashboard

The main administrative interface for monitoring reports, reviewing statistics, and managing system activities.

### 2. Main Pages

Core application pages that provide navigation and access to reporting services.

### 3. Login Page

Secure authentication page for authorized users and administrators.

### 4. District Administration (Admin Kecamatan)

Dedicated management panel for district-level administrators to handle reports within their respective regions.
